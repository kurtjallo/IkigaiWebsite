# Ikigai Consulting Group

**Organizational Architects for Purpose-Driven Organizations**

Ikigai Consulting Group designs and strengthens the structural foundations that allow purpose-driven organizations to lead with clarity and deliver measurable impact. This repository contains the source code for the official Ikigai website.

---

## Overview

Ikigai aligns strategy, governance, operations, and leadership to turn vision into measurable impact. The website serves as the digital presence for the firm, showcasing the proprietary **Ikigai Architecture Model** and the seven pillars of organizational architecture.

## Site Structure

| Page | Purpose |
|------|---------|
| **Homepage** | Authority landing page with hero, problem statement, solution overview, 7 pillars, audience, and CTA |
| **About** | Founder bio (Nilda Bastone), philosophy, and organizational values |
| **Services** | Detailed breakdown of each of the 7 architectural pillars |
| **The Ikigai Model** | Signature thought-leadership page for the Ikigai Architecture Model |
| **Case Studies / Impact** | Real-world results with challenge, approach, outcome, and metrics |
| **Contact** | Inquiry form and calendar booking integration |

## The 7 Pillars

1. **Strategic Architecture** -- Vision-to-action alignment
2. **Governance Architecture** -- Board and oversight structures
3. **Operational Architecture** -- Systems and process design
4. **Program Architecture** -- Program design and delivery
5. **Leadership Architecture** -- Executive and team development
6. **Accountability Architecture** -- Performance and reporting frameworks
7. **Community Architecture** -- Stakeholder and community engagement

## Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd ikigaiWebsite

# Install dependencies
npm install

# Start development server
npm run dev
```
