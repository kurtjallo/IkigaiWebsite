  <action>
    Wire the structured data schemas into the actual pages as JSON-LD script tags.

    **1. Update `src/app/layout.tsx`:**

    Import `organizationSchema` and `localBusinessSchema` from `@/lib/data/structured-data`.

    Add two `<script type="application/ld+json">` tags inside the `<head>` section (or as children of `<body>` -- both are valid for JSON-LD). Place them at the end of `<body>` before `{children}` is rendered, or use Next.js `<Script>` if appropriate.

    The recommended approach for Next.js App Router is to render them directly in JSX:

    ```tsx
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{
        __html: JSON.stringify(organizationSchema),
      }}
    />
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{
        __html: JSON.stringify(localBusinessSchema),
      }}
    />
    ```

    Place these inside the `<body>` tag, before the main content. They are invisible to users but readable by search engine crawlers.

    IMPORTANT: Do NOT modify the existing layout structure (navigation, main, footer). Only ADD the JSON-LD script tags.

    **2. Update `src/app/services/page.tsx`:**

    Import `getServiceSchemas` from `@/lib/data/structured-data`.

    Add the Service JSON-LD schemas to the services page. Render all 7 service schemas as a single script tag containing an array, OR as 7 separate script tags. The array approach is cleaner:

    ```tsx
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{
        __html: JSON.stringify(getServiceSchemas()),
      }}
    />
    ```

    Place this at the top of the page component's return value, before the section components.

    IMPORTANT: Do NOT modify the existing page structure or section components. Only ADD the JSON-LD script tag.

    **3. Validation approach:**
