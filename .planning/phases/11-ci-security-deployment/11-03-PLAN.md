  <action>
    Install the Vercel Analytics package and add the Analytics component to the root layout.

    **1. Install @vercel/analytics:**

    ```bash
    npm install @vercel/analytics
    ```

    **2. Update `src/app/layout.tsx`:**

    Add the `<Analytics />` component from `@vercel/analytics/next` to the root layout body. This must be:
    - Imported from `@vercel/analytics/next` (NOT `@vercel/analytics/react` -- the `/next` import includes Next.js route change tracking)
    - Placed inside `<body>` after `{children}`
    - Not wrapped in any conditional -- it automatically no-ops in non-Vercel environments (local dev, CI)

    Example of what the updated layout should look like (merge with existing layout, do NOT replace existing content):

    ```typescript
    import { Analytics } from '@vercel/analytics/next';

    // In the return JSX, add <Analytics /> after {children}:
    <body>
      {/* existing content: Navigation, main, Footer, etc. */}
      {children}
      <Analytics />
    </body>
    ```

    IMPORTANT: The existing layout has fonts, metadata, navigation, footer, and other elements from previous phases. Do NOT remove or modify any of those. ONLY add the Analytics import and component.

    **3. Verify the import path:**

    The import MUST be `@vercel/analytics/next`, not:
    - `@vercel/analytics` (generic, no route tracking)
    - `@vercel/analytics/react` (React-specific, no Next.js route tracking)

    The `/next` import automatically handles:
    - Page view tracking on route changes
    - Privacy-friendly (no cookies)
    - Automatic no-op when not deployed to Vercel
    - Tree-shaking (zero bundle impact in non-Vercel environments)

  <how-to-verify>
    **Step 1: Deploy to Vercel**
    1. Go to https://vercel.com/new
    2. Import your GitHub repository (ikigaiWebsite)
    3. Vercel will auto-detect Next.js and configure the build
    4. Click "Deploy" -- the first deployment should complete in ~30 seconds
    5. Verify the site loads at the Vercel-provided URL (e.g., ikigai-website-xxx.vercel.app)

    **Step 2: Enable Analytics**
    1. In the Vercel Dashboard, go to your project
    2. Navigate to the "Analytics" tab
    3. Click "Enable" to activate Web Analytics
    4. Visit your deployed site and navigate between pages
    5. Return to the Analytics tab -- you should see page view data appearing

    **Step 3: Configure Custom Domain (when ready)**
    1. In the Vercel Dashboard, go to Project -> Settings -> Domains
    2. Add your custom domain (e.g., ikigaiconsulting.ca)
    3. Follow the DNS configuration instructions Vercel provides
    4. Vercel will auto-provision an SSL certificate

    **Step 4: Verify Security Headers**
    1. Visit your deployed site
    2. Open browser DevTools -> Network tab
    3. Click on the document request (the HTML page)
    4. Check Response Headers -- you should see:
       - Content-Security-Policy (with Calendly, Formspree, Vercel Analytics allowlisted)
       - Strict-Transport-Security (max-age=63072000)
       - X-Frame-Options: DENY
       - X-Content-Type-Options: nosniff
       - Referrer-Policy: strict-origin-when-cross-origin
       - Permissions-Policy (camera, microphone, geolocation disabled)

    **Step 5: Verify CI Pipeline**
    1. Create a test PR or push to main
    2. Go to the GitHub repository -> Actions tab
    3. Verify the CI workflow runs with all jobs (quality + e2e)
    4. Verify Vercel automatically creates a deploy preview for the PR

    **Step 6: Verify Deploy Previews**
    1. Create a PR against main
    2. Vercel should automatically comment on the PR with a preview URL
    3. Visit the preview URL to verify it works
  </how-to-verify>
