  <action>
    Create a single file that exports a `PillarIcon` component which renders the correct SVG icon based on a pillar `type` prop.

    **Architecture:**

    ```typescript
    import { cn } from '@/lib/utils'

    interface PillarIconProps {
      type: 'strategic' | 'governance' | 'operational' | 'program' | 'leadership' | 'accountability' | 'community'
      className?: string
      size?: number    // defaults to 24
    }
    ```

    The `PillarIcon` component selects the correct icon SVG based on `type` and renders it.

    **All icons share these properties:**
    - `viewBox="0 0 24 24"`
    - `stroke="currentColor"` (inherits text color from parent via Tailwind)
    - `fill="none"` (line art only, no solid fills)
    - `strokeWidth="1.5"` (consistent line weight)
    - `strokeLinecap="round"` and `strokeLinejoin="round"` (smooth line endings)
    - `width` and `height` from `size` prop (default 24)
    - `aria-hidden="true"` (decorative icons, text label provides meaning)

    **Icon designs (all line art, no fills):**

    1. **Strategic** (compass/direction): A circle with a diamond/arrow pointing north. Draw a circle (cx=12, cy=12, r=9), then a diamond rotated 45deg inside pointing upward (representing direction/north star). Add small tick marks at N/S/E/W.

    2. **Governance** (balanced scale): A triangle (equilateral, pointing up) as the base/fulcrum, with a horizontal line across the top, and two small hanging plates (short vertical lines ending in small arcs or rectangles) on each side. Represents balance, fairness, structured oversight.

    3. **Operational** (interlocking gears): Two circles (gears) of different sizes, slightly overlapping. Each with 6-8 small rectangular teeth around the perimeter. Keep it minimal -- suggest gears, don't draw every tooth in detail. Use `<circle>` for the gear bodies and small `<line>` or `<rect>` elements for teeth.

    4. **Program** (flowchart/connected nodes): 3 circles connected by lines in a tree structure: one circle at top, two below, connected by lines going down and branching. Represents structured program flow. Use `<circle>` for nodes (r=3) and `<line>` for connections.

    5. **Leadership** (north star/guiding light): A 4-pointed star with elongated vertical and horizontal points (like a compass rose, but star-shaped). Radiating short lines from the center between the points. Represents guidance, direction, aspiration.

    6. **Accountability** (target/measurement): 3 concentric circles (target rings) with a small dot at the center. Add two short crosshair lines extending beyond the outer ring at top and right. Represents precision, measurement, hitting targets.

    7. **Community** (connected network): 5 small circles (nodes) arranged in a rough pentagon pattern, connected by lines to form a network. Each node represents a person/organization. The connections represent community bonds. Use `<circle>` for nodes (r=2.5) and `<line>` for connections.

    **Important design notes:**
    - These should look like they belong together as a family -- consistent stroke weight, similar level of detail, similar visual density
    - They should be recognizable at small sizes (used in cards at ~32-48px)
    - They should NOT look like Lucide or Heroicons -- these are custom brand icons with an architectural quality
    - Architectural quality means: geometric precision, clean lines, structural logic -- not organic or hand-drawn

    Each icon is defined as a private function component within the file. The exported `PillarIcon` component uses a map to select the correct one.

    ```typescript
    const iconMap = {
      strategic: StrategicIcon,
      governance: GovernanceIcon,
      operational: OperationalIcon,
      program: ProgramIcon,
      leadership: LeadershipIcon,
      accountability: AccountabilityIcon,
      community: CommunityIcon,
    }

    export function PillarIcon({ type, className, size = 24 }: PillarIconProps) {
      const IconComponent = iconMap[type]
      return <IconComponent className={className} size={size} />
    }
    ```

  <name>Task 2: Create architectural decorative motif SVG components</name>
  <files>
    src/components/svg/architectural-motifs.tsx

  <action>
    Create decorative architectural line drawing components that will be used as subtle visual elements throughout the site. These are background/accent decorations, not content -- they add the "architectural firm" aesthetic described in DSGN-07.

    **3 motif components:**

    **1. CornerAccent** -- L-shaped bracket decorations for section corners

    ```typescript
    interface CornerAccentProps {
      position: 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right'
      className?: string
      size?: number    // default 48
    }
    ```

    Design: Two perpendicular lines forming an L-shape (like architectural drawing corner marks). The position prop rotates/mirrors the L to fit each corner. Thin stroke (1px), subtle.

    Example for top-left:
    - A vertical line going down ~40% of size from the top
    - A horizontal line going right ~40% of size from the left
    - Both lines meet at the top-left corner

    Use CSS transform (via style prop or className) to flip for other positions. Or draw each position's path explicitly.

    **2. BlueprintGrid** -- Subtle grid pattern for section backgrounds

    ```typescript
    interface BlueprintGridProps {
      className?: string
      opacity?: number    // default 0.05
    }
    ```

    Design: A repeating grid pattern using SVG `<pattern>` and `<rect>`. Creates a subtle blueprint paper effect when placed behind section content. Very low opacity (0.03-0.08) so it doesn't compete with content.

    Implementation:
    - SVG with `width="100%" height="100%"`
    - `<defs>` containing a `<pattern>` with id, 40x40 unit cell
    - Pattern contains thin horizontal and vertical lines (strokeWidth 0.5)
    - `<rect>` filling the SVG using the pattern
    - `stroke="currentColor"` so Tailwind text color controls it
    - Position: absolute, inset-0, pointer-events-none (purely decorative)

    **3. StructuralFrame** -- A decorative frame element suggesting architectural structure

    ```typescript
    interface StructuralFrameProps {
      className?: string
      variant?: 'horizontal' | 'vertical'
    }
    ```

    Design: A series of parallel lines with perpendicular cross-members, suggesting a structural beam or truss. Used as a decorative divider or accent.

    For 'horizontal' variant:
    - Two long horizontal lines (top and bottom of frame)
    - 3-5 short vertical lines connecting them at regular intervals
    - Small diagonal braces in between (like a truss pattern)
    - viewBox proportioned wide and short (e.g., "0 0 200 24")

    For 'vertical' variant:
    - Same design but rotated 90 degrees
    - viewBox proportioned tall and narrow (e.g., "0 0 24 200")

    All lines use `stroke="currentColor"`, `fill="none"`, strokeWidth 1.

    **Important notes for all motifs:**
    - These are purely decorative -- `aria-hidden="true"` on all SVGs
    - Use `currentColor` for all strokes so Tailwind text color classes control the color
    - Default opacity should be LOW (these whisper, they don't shout)
    - Components should be positioned absolute/relative by the parent -- they just render the SVG shapes
    - Keep SVG paths simple -- these render many times across the site, so file size matters
