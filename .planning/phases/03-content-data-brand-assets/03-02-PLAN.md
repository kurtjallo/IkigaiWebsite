  <action>
    Create an SVG React component that renders the Ikigai Consulting Group wordmark.

    The logo is text-based (no pictorial mark). It should convey architectural precision and premium authority.

    **Design:**
    - "IKIGAI" in uppercase, Playfair Display (serif), larger and bolder -- this is the primary brand name
    - "CONSULTING GROUP" in uppercase, Inter (sans-serif), smaller, letter-spaced -- the descriptor line below
    - A gold accent element: a short horizontal line (2-3px thick) between "IKIGAI" and "CONSULTING GROUP", acting as a structural divider (architectural motif)
    - Clean, minimal -- no decoration beyond the accent line

    **Implementation as an SVG component:**

    ```typescript
    interface LogoProps {
      variant?: 'dark' | 'light'  // dark = dark text (for light backgrounds), light = white text (for dark backgrounds)
      className?: string
      showTagline?: boolean       // Whether to show "CONSULTING GROUP" line (false for compact/mobile use)
    }
    ```

    Use inline SVG with `<text>` elements. Set `viewBox` for proper aspect ratio scaling. The component should be responsive -- it scales based on its container width.

    **Color handling:**
    - `dark` variant: "IKIGAI" in `#111111` (near-black), "CONSULTING GROUP" in `#555555` (muted), gold accent line in `#D4A843`
    - `light` variant: "IKIGAI" in `#FFFFFF`, "CONSULTING GROUP" in `#D4E2D6` (hunter-green-100, muted white), gold accent line in `#D4A843`
    - Gold accent line is always `#D4A843` regardless of variant

    **Font handling in SVG:** Use `fontFamily: "'Playfair Display', Georgia, serif"` and `fontFamily: "'Inter', system-ui, sans-serif"` on the `<text>` elements. These will pick up the web fonts loaded by next/font in the browser. For contexts where fonts aren't loaded (e.g., raw SVG viewing), Georgia and system-ui are acceptable fallbacks.

    **SVG viewBox:** Use a viewBox that accommodates both text lines with the accent. Something like `viewBox="0 0 300 80"` for the full version, adjustable based on actual text metrics. The exact viewBox dimensions should be calibrated so text renders at a readable size -- if the text looks too small or too large, adjust the viewBox and font sizes accordingly.

    **Accessibility:** Include a `<title>` element inside the SVG: "Ikigai Consulting Group". Add `role="img"` and `aria-label="Ikigai Consulting Group"` to the SVG element.

    NOTE: SVG `<text>` elements with web fonts can be tricky. Test that the text renders correctly in the browser with next/font loaded. The fallback fonts (Georgia, system-ui) should be visually acceptable if web fonts haven't loaded yet.
  </action>

    Create programmatically generated brand icons and OG image using Next.js file conventions and ImageResponse from next/og.

    **1. src/app/icon.tsx -- 32x32 PNG favicon**

    Uses `ImageResponse` from `next/og` to generate a 32x32 PNG icon at build time.

    Design: Hunter green (#355E3B) square background with a stylized "I" letterform in gold (#D4A843). The "I" should be in a serif style (bold, architectural). Keep it very simple -- at 16x16 it must still be recognizable.

    ```typescript
    import { ImageResponse } from 'next/og'

    export const size = { width: 32, height: 32 }
    export const contentType = 'image/png'

    export default function Icon() {
      return new ImageResponse(
        (
          <div style={{
            width: '100%',
            height: '100%',
            display: 'flex',
            alignItems: 'center',
            justifyContent: 'center',
            background: '#355E3B',
            borderRadius: '4px',
          }}>
            <span style={{
              fontSize: '22px',
              fontWeight: 700,
              color: '#D4A843',
              fontFamily: 'Georgia, serif',
            }}>
              I
            </span>
          </div>
        ),
        { ...size }
      )
    }
    ```

    **2. src/app/apple-icon.tsx -- 180x180 Apple touch icon**

    Same design as the favicon but at 180x180 for iOS home screens. Can include slightly more detail at this size.

    Design: Hunter green background, larger "I" letterform in gold, with a thin gold horizontal line below the "I" (echoing the logo's accent line). Rounded corners (the OS will apply its own mask, but a subtle borderRadius helps).

    ```typescript
    export const size = { width: 180, height: 180 }
    export const contentType = 'image/png'
    ```

    **3. src/app/favicon.ico -- Static ICO file**

    Generate a simple favicon.ico file. Since ICO generation is complex programmatically, create a minimal approach:
    - Create a simple 48x48 PNG using ImageResponse in a temporary build step, OR
    - Create the favicon.ico as a static file with the same hunter green + gold "I" design

    The simplest approach: create a small script or use the Next.js icon.tsx as the primary favicon and place a minimal static favicon.ico for legacy browsers. The ICO can be a simple 1x1 or 16x16 green square as fallback -- modern browsers will prefer the PNG from icon.tsx.

    PRACTICAL NOTE: Creating a proper .ico file programmatically is non-trivial. The recommended approach is:
    1. Create the icon.tsx (which generates the PNG favicon) -- this is what modern browsers use
    2. For favicon.ico, create a minimal placeholder. The icon.tsx will be the primary favicon.
    3. If a proper .ico is needed later, it can be generated from the PNG using an online tool or npm package

    For now, create a minimal favicon.ico. You can generate one by:
    - Using a 16x16 PNG converted to ICO format
    - Or placing a simple placeholder .ico file

    The icon.tsx programmatic icon is the primary favicon and works in all modern browsers.

    **4. src/app/opengraph-image.tsx -- 1200x630 OG image**

    Uses `ImageResponse` from `next/og` to generate a branded OG image at build time.

    Design:
    - Background: Hunter green (#355E3B) full bleed
    - Top area: "IKIGAI" in large serif text (white), "CONSULTING GROUP" below in smaller sans-serif (gold)
    - A gold horizontal accent line between the name and tagline
    - Bottom area: "Organizational Architects for Purpose-Driven Organizations" in white sans-serif
    - Subtle gold border or corner accents for premium feel
    - Clean, minimal -- consistent with brand aesthetic

    ```typescript
    import { ImageResponse } from 'next/og'

    export const alt = 'Ikigai Consulting Group - Organizational Architects for Purpose-Driven Organizations'
    export const size = { width: 1200, height: 630 }
    export const contentType = 'image/png'
    ```

    NOTE on fonts in ImageResponse: The Satori renderer (used by ImageResponse) does not have access to web fonts by default. For the OG image, use system fonts that approximate the brand feel:
    - Serif: `Georgia, 'Times New Roman', serif` (approximates Playfair Display)
    - Sans-serif: `'Helvetica Neue', Arial, sans-serif` (approximates Inter)

    If higher fidelity is needed later, font files can be loaded via `readFile` from an assets directory. For now, system font approximation is acceptable for OG images -- they're small preview cards on social media.
