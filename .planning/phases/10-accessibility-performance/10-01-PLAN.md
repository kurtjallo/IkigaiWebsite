Create a custom branded 404 page that maintains the premium Ikigai design language when visitors hit a non-existent route.

Purpose: A generic browser 404 page breaks the premium experience. A branded 404 keeps visitors within the site's authority positioning and guides them back to useful content.

Output: A `not-found.tsx` page with consistent site branding, helpful messaging, and a clear path back to the homepage.

  <name>Task 1: Create custom branded 404 page</name>
  <files>src/app/not-found.tsx</files>
  <action>
    Create `src/app/not-found.tsx` as a Next.js App Router not-found page. This file is automatically rendered by Next.js when `notFound()` is called or when no route matches.

    The page should:

    1. **Use existing design system components**: Import Section, Container, SectionHeading, Button from `@/components/ui/`. Do NOT create new components.

    2. **Layout**: The page is wrapped by the root layout (navigation + footer are automatic), so only the page content is needed. Use a Section component with either `white` or `hunter-green` background.

    3. **Content structure**:
       - SectionHeading with heading "Page Not Found" (h1)
       - A short, professional paragraph: "The page you're looking for doesn't exist or has been moved." -- keep it warm but concise, consistent with the sophisticated brand tone.
       - A gold CTA Button linking to "/" with text "Return to Homepage"
       - Optionally, a subtle architectural line motif or decorative element if SVG components are available

    4. **Styling**: Center the content vertically within the section. Use generous whitespace. The page should feel intentional, not like an error. Minimum height to fill the viewport (use `min-h-[60vh]` or similar with flex centering).

    5. **Metadata**: Export a `metadata` object with:
       ```typescript
       export const metadata: Metadata = {
         title: 'Page Not Found',
         description: 'The page you are looking for does not exist.',
         robots: { index: false, follow: true },
       }
       ```
       The `robots` config prevents search engines from indexing the 404 page while still following links on it.

    Do NOT add any animations or client-side interactivity. This is a Server Component.
  </action>
  <verify>
    - `npx tsc --noEmit` passes with no type errors
    - `npm run build` succeeds (static export produces the 404 page)
    - `ls out/404.html` confirms the 404 page is in the static output
    - Navigating to a non-existent route (e.g., /nonexistent) shows the branded 404 page with nav, footer, and gold CTA
  </verify>
