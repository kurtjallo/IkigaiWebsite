    **2. Skip navigation link (`src/components/layout/skip-nav.tsx`)**

    Create a skip navigation link for accessibility (A11Y-05). This is a Server Component.

    The skip nav link:
    - Is visually hidden by default (positioned off-screen)
    - Becomes visible when focused via keyboard (Tab key)
    - Links to `#main-content` (the id that will be placed on the `<main>` element in the root layout)
    - Styled with gold background, black text (matches the brand CTA style)
    - Has a focus style that makes it clearly visible: positioned at top-left of viewport, z-50

    ```tsx
    export function SkipNav() {
      return (
        <a
          href="#main-content"
          className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-50 focus:bg-gold focus:text-black focus:px-4 focus:py-2 focus:rounded-sm focus:font-semibold focus:outline-2 focus:outline-offset-2 focus:outline-gold"
        >
          Skip to main content
        </a>
      )
    }
    ```

    NOTE: The `sr-only` / `focus:not-sr-only` pattern is the standard Tailwind approach for skip links. Verify the exact Tailwind v4 class names work -- `sr-only` should be available in Tailwind v4.
  </action>

The actual logo/wordmark will be swapped in during Phase 3. Use `text-hunter-green font-serif text-xl font-bold tracking-wide` for the wordmark.
    - Display desktop navigation links on the right, visible on `lg:` breakpoint and above (`hidden lg:flex`)
    - Show a hamburger menu button on screens smaller than `lg:` (`lg:hidden`)
    - Indicate the current page with a gold underline/accent on the active link
    - Use `usePathname()` from `next/navigation` to determine the current page
    - Render the MobileMenu component (passing open state and close handler)
    - Be sticky at the top: `sticky top-0 z-40`
    - Have a white background with subtle bottom border: `bg-white border-b border-neutral-200`
    - Use Container from `@/components/ui/container` for horizontal padding/max-width

    Desktop link styling:
    - `text-sm font-sans font-medium tracking-wide uppercase`
    - Default: `text-neutral-700 hover:text-hunter-green`
    - Active (current page): `text-hunter-green` with a `border-b-2 border-gold` underline (2px gold bottom border using padding-bottom to offset)
    - Focus: `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-gold` (A11Y-04)
    - Use `next/link` for all navigation links

    Hamburger button styling:
    - Use `Menu` icon from `lucide-react` (24x24)
    - `text-neutral-700 hover:text-hunter-green`
    - `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-gold`
    - `aria-label="Open menu"` for screen readers
    - `aria-expanded` attribute reflecting mobile menu state

    Navigation element:
    - Wrap in `<nav aria-label="Main navigation">` for accessibility
    - Inner layout: flex with justify-between, items-center
    - Height: `h-16 md:h-20` (64px mobile, 80px desktop)

    **2. Mobile menu (`src/components/layout/mobile-menu.tsx`)**

    This is a `'use client'` component that renders a full-screen overlay menu on mobile.

    Props:
    - `isOpen`: boolean
    - `onClose`: () => void

    Behavior:
    - When `isOpen` is true, render a full-screen overlay
    - Overlay background: `bg-white` (full white, clean premium feel)
    - Close button in top-right: `X` icon from `lucide-react`, with `aria-label="Close menu"`
    - Display all navigation links vertically, centered
    - Each link: `text-h3 font-serif text-neutral-900 hover:text-hunter-green`
    - Active link (current page): `text-hunter-green` with gold accent (same as desktop)
    - Use `usePathname()` to determine active link
    - Close menu when a link is clicked (call `onClose`)
    - Trap focus within the menu when open (use `aria-modal="true"` and `role="dialog"`)
    - Set `aria-label="Mobile navigation menu"` on the dialog
    - Close on Escape key press (add keyboard event listener)
    - Prevent body scroll when open (add `overflow-hidden` to body via useEffect)
    - Position: `fixed inset-0 z-50`
    - Animate: simple fade-in. Use CSS transition or conditional classes:
      - When open: `opacity-100 visible`
      - When closed: `opacity-0 invisible`
      - `transition-all duration-300`

    Link styling in mobile menu:
    - Stack vertically with generous spacing: `space-y-6` or `space-y-8`
    - Centered: `flex flex-col items-center justify-center min-h-screen`
    - Each link uses `next/link`
    - Focus: `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-gold`
    - Links should be large tap targets (minimum 44px height per A11Y standards)

    IMPORTANT: When a navigation link is clicked in the mobile menu, call `onClose()` to close the menu. Use the `usePathname()` hook change to detect navigation and close, OR simply attach `onClick={onClose}` to each link.

    IMPORTANT: The mobile menu must be keyboard accessible (A11Y-02):
    - Tab through all links
    - Escape closes the menu
    - When menu opens, focus the first link or the close button
    - When menu closes, return focus to the hamburger button (pass a ref or use document.activeElement pattern)
