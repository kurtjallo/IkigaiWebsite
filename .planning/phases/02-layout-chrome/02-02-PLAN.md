<task type="auto">
  <name>Task 2: Wire layout chrome into root layout</name>
  <files>
    src/app/layout.tsx
  </files>
  <action>
    Update the root layout (`src/app/layout.tsx`) to compose the complete layout chrome: SkipNav, Navigation, main content area, and Footer. This is the file that wraps ALL pages.

    **Update `src/app/layout.tsx` to:**

    1. Import all layout components:
       - `SkipNav` from `@/components/layout/skip-nav`
       - `Navigation` from `@/components/layout/navigation`
       - `Footer` from `@/components/layout/footer`

    2. Keep existing font and metadata configuration from Phase 1 (do NOT remove these):
       - Font imports from `@/lib/fonts`
       - Font variable CSS classes on `<html>` element
       - `globals.css` import
       - Metadata export

    3. Structure the body content in this order:
       ```tsx
       <body className="font-sans antialiased">
         <SkipNav />
         <Navigation />
         <main id="main-content" className="flex-1">
           {children}
         </main>
         <Footer />
       </body>
       ```

    4. Make body a flex column to push footer to bottom on short pages:
       - Add `flex flex-col min-h-screen` to the body className
       - The `flex-1` on main ensures it takes remaining space, pushing footer down

    5. The `id="main-content"` on `<main>` is CRITICAL -- this is the target of the SkipNav link. Without it, the skip navigation link does nothing.

    6. Keep the `<html>` element attributes:
       - `lang="en"`
       - Font variable classes: `${playfairDisplay.variable} ${inter.variable}`

    **IMPORTANT: Do NOT add `'use client'` to layout.tsx.** The root layout is a Server Component. The Navigation component has its own `'use client'` directive -- it will be rendered as a client island within the server-rendered layout. This is the correct pattern.

    **After wiring, verify the existing showcase page (from Phase 1) still renders correctly.** The showcase page at `/` should now appear with navigation at top and footer at bottom, with all the design system content between them.
  </action>

    - `npm run dev` shows the showcase page with navigation at top, footer at bottom

    - Footer at bottom of page (pushed down by flex layout even on short pages)
    - Skip nav link appears when pressing Tab on page load
    - Skip nav link jumps focus to main content area
    - `main` element has `id="main-content"`
    - Body has `flex flex-col min-h-screen`
    - `npx tsc --noEmit` passes
    - Layout does NOT have `'use client'` directive
  </verify>
