    Server Component (no 'use client'). Uses existing UI primitives (Section, Container, SectionHeading, Button, Divider).

    Props interface:
    ```typescript
    interface ServicePillarProps {
      pillar: Pillar           // from @/lib/data/pillars (the Pillar type)
      background: 'white' | 'light-green'  // alternating per section
      index: number            // pillar index (0-6) for anchor IDs
    }
    ```

    Import the `Pillar` type from `@/lib/data/pillars`. If the type doesn't exist yet or the data file structure differs, adapt to whatever interface the pillars.ts data file exposes. The key fields needed are: `slug`, `title`, `subtitle` (or short tagline), `description` (paragraph), `included` (string array), `outcomes` (string array), and `icon` (string key for the pillar icon).

    Layout (two-column on desktop, stacked on mobile):
    - Section wrapper with the `background` prop for alternating backgrounds
    - `id` attribute set to `pillar.slug` for anchor linking from homepage pillars grid
    - Two-column grid: `grid md:grid-cols-2 gap-12 items-start`

    Left column (content):
    - SectionHeading with:
      - `tagline`: pillar subtitle or "Pillar {index + 1} of 7"
      - `heading`: pillar title (e.g., "Strategic Architecture")
      - `align`: "left"
      - `headingAs`: "h2"
    - Description paragraph: `text-body-lg text-neutral-700 mt-6` (or text-neutral-300 on dark backgrounds, but services uses only white/light-green so text-neutral-700 is correct)
    - Gold Divider below description: `my-8`

    Right column (details):
    - **What's Included** box:
      - Heading: `font-serif text-h4 mb-4` -- "What's Included"
      - Bulleted list of included items from `pillar.included`
      - List styling: `space-y-2`, each item with a gold bullet (use a `before:content-[''] before:w-1.5 before:h-1.5 before:rounded-full before:bg-gold before:inline-block before:mr-3` pseudo-element or a flex layout with a gold dot)

    - **Outcomes** box (below What's Included):
      - Heading: `font-serif text-h4 mb-4 mt-8` -- "Outcomes"
      - Bulleted list of outcomes from `pillar.outcomes`
      - Same bullet styling as included list

    - CTA Button at bottom of right column:
      - `<Button href="/contact" variant="gold">Schedule a Strategic Conversation</Button>`
      - `mt-8` spacing above the button

    Responsive behavior:
    - Desktop (md+): Two-column layout, content left, details right
    - Mobile: Single column, content stacked above details
    - All text is readable at mobile sizes

  <name>Task 2: Compose Services page route with 7 pillar sections</name>
  <files>
    src/app/services/page.tsx

  <action>
    Create the Services page route that renders all 7 pillar sections with alternating backgrounds and gold dividers.

    **src/app/services/page.tsx:**

    ```typescript
    import type { Metadata } from 'next'
    import { pillars } from '@/lib/data/pillars'
    import { ServicePillar } from '@/components/sections/service-pillar'
    import { Divider } from '@/components/ui/divider'
    import { Section } from '@/components/ui/section'
    import { SectionHeading } from '@/components/ui/section-heading'

    export const metadata: Metadata = {
      title: 'Services',
      description: 'Seven pillars of organizational architecture for purpose-driven organizations. Strategic, Governance, Operational, Program, Leadership, Accountability, and Community Architecture.',
    }

    export default function ServicesPage() {
      return (
        <>
          {/* Page intro section */}
          <Section background="hunter-green">
            <SectionHeading
              tagline="Our Services"
              heading="Seven Pillars of Organizational Architecture"
              description="Each pillar addresses a critical dimension of organizational health. Together, they form a complete architecture for purpose-driven organizations that don't just survive — they thrive."
              align="center"
              headingAs="h1"
              dark
            />
          </Section>

          {/* 7 pillar detail sections with alternating backgrounds */}
          {pillars.map((pillar, index) => (
            <div key={pillar.slug}>
              <ServicePillar
                pillar={pillar}
                background={index % 2 === 0 ? 'white' : 'light-green'}
                index={index}
              />
              {/* Gold divider between sections (not after last) */}
              {index < pillars.length - 1 && <Divider />}
            </div>
          ))}

          {/* Bottom CTA section */}
          <Section background="hunter-green">
            <div className="text-center">
              <SectionHeading
                heading="Ready to Architect Your Organization?"
                description="Every strong organization starts with a conversation about what's possible."
                align="center"
                headingAs="h2"
                dark
              />
              {/* Import Button from ui */}
            </div>
          </Section>
        </>
      )
    }
    ```

    Key implementation details:

    1. **Page intro**: A hunter-green hero section with the page title "Seven Pillars of Organizational Architecture" as h1. This establishes the page visually before the detail sections.

    2. **Alternating backgrounds (DSGN-06)**: Use modulo on the pillar index -- even indices get white, odd indices get light-green. This creates the visual rhythm specified in the design requirements.

    3. **Gold dividers**: Render a Divider component between each pillar section (but not after the last one). The Divider sits between Section components, creating a gold separator line.

    4. **Bottom CTA**: A hunter-green section with heading "Ready to Architect Your Organization?" and a gold CTA button linking to /contact with text "Schedule a Strategic Conversation". Import Button from `@/components/ui/button` for this.

    5. **Anchor IDs**: Each ServicePillar renders with `id={pillar.slug}`, enabling links from the homepage pillars grid (e.g., /services#strategic).

    6. **Data-driven**: The page imports the `pillars` array and maps over it. No pillar content is hardcoded in the page file. If a pillar is added or modified, only `pillars.ts` needs to change.

    The page is a Server Component (no 'use client'). Static export will produce `/services/index.html` (or `services.html` depending on trailingSlash config).
  </action>
