    **Step 1: Install Motion**

    ```bash
    npm install motion
    ```

    This installs `motion` v12.x (the library formerly known as framer-motion). Import from `motion/react` in all animation components.

    **Step 2: Create FadeIn component (`src/components/animation/fade-in.tsx`)**

    A Client Component that wraps children in a `motion.div` with scroll-triggered fade-up animation.

    ```tsx
    'use client'

    import { motion, useReducedMotion } from 'motion/react'
    import { type ReactNode } from 'react'

    interface FadeInProps {
      children: ReactNode
      delay?: number           // delay in seconds before animation starts (default: 0)
      direction?: 'up' | 'down' | 'left' | 'right'  // direction content fades from (default: 'up')
      className?: string
    }
    ```

    Implementation details:
    - Use `useReducedMotion()` hook. When true, set `initial` to `false` (renders in final state immediately, no animation).
    - Direction offsets: up = `{ y: 30 }`, down = `{ y: -30 }`, left = `{ x: 30 }`, right = `{ x: -30 }`. These are transform-only (ANIM-05 compliant).
    - `whileInView` animates to `{ opacity: 1, x: 0, y: 0 }`.
    - `viewport={{ once: true, margin: '-100px' }}` -- animate once, trigger 100px inside viewport edge.
    - `transition={{ duration: 0.6, delay, ease: 'easeOut' }}` -- 600ms with easeOut feels like 300ms perceived (ANIM-01 compliant).
    - When reduced motion is preferred: `initial={false}` skips to final state, no motion.div animation props set.

    **Step 3: Create StaggerChildren component (`src/components/animation/stagger-children.tsx`)**

    Two exports: `StaggerChildren` (parent container) and `StaggerItem` (individual child wrapper).

    ```tsx
    'use client'

    import { motion, useReducedMotion } from 'motion/react'
    import { type ReactNode } from 'react'

    interface StaggerChildrenProps {
      children: ReactNode
      staggerDelay?: number   // delay between each child in seconds (default: 0.1)
      className?: string
    }

    interface StaggerItemProps {
      children: ReactNode
      className?: string
    }
    ```

    Implementation details:
    - Parent (`StaggerChildren`): Uses `initial="hidden"`, `whileInView="visible"`, `viewport={{ once: true, margin: '-50px' }}`.
    - Parent variants: `hidden: {}`, `visible: { transition: { staggerChildren: staggerDelay } }`.
    - Child (`StaggerItem`): Uses `variants` only (inherits trigger from parent).
    - Child variants: `hidden: { opacity: 0, y: 20 }`, `visible: { opacity: 1, y: 0, transition: { duration: 0.5, ease: 'easeOut' } }`.
    - Only `opacity` and `y` (translateY) animated -- ANIM-05 compliant.
    - Reduced motion: When `useReducedMotion()` returns true in `StaggerChildren`, set `initial` to `false` instead of `"hidden"`, and don't set `whileInView`. Children render in their visible state immediately. The `StaggerItem` should also check reduced motion and skip variants if true (set `initial` to `false`).

    IMPORTANT: `useReducedMotion` is a hook, so it can only be called in Client Components. Both `StaggerChildren` and `StaggerItem` are already Client Components (same file, `'use client'` at top), so this works.

    **Step 4: Create HoverAccent component (`src/components/animation/hover-accent.tsx`)**

    A Client Component that adds a gold accent line animation on hover.

    ```tsx
    'use client'

    import { motion, useReducedMotion } from 'motion/react'
    import { type ReactNode } from 'react'

    interface HoverAccentProps {
      children: ReactNode
      className?: string
      position?: 'bottom' | 'top'  // where the gold line appears (default: 'bottom')
    }
    ```

    Implementation details:
    - Wrapper: `motion.div` with `whileHover="hovered"`, `initial="initial"` variant trigger.
    - Gold accent line: An absolutely positioned `motion.div` inside the wrapper with `className="absolute left-0 right-0 h-0.5 bg-gold origin-left"` (plus `bottom-0` or `top-0` based on `position` prop).
    - Accent line variants: `initial: { scaleX: 0 }`, `hovered: { scaleX: 1 }`. Uses `scaleX` (transform) instead of `width` to stay GPU-composited (ANIM-05 compliant). The `origin-left` class ensures scaling from the left edge.
    - Transition on accent: `{ duration: 0.3, ease: 'easeOut' }`.
    - Wrapper needs `className="relative overflow-hidden"` merged with the passed `className`.
    - Reduced motion: When `useReducedMotion()` is true, render children without the motion wrapper -- just a plain `div` with `className` applied. The gold accent line can be shown statically (always visible) or hidden entirely. Recommend: show it statically at `scaleX: 1` so the visual indicator is present without animation.

    Use `cn()` from `@/lib/utils` to merge classNames in all three components.
