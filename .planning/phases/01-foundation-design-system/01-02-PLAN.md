  <action>
    Create 6 UI primitive components in `src/components/ui/`. All components must:
    - Accept a `className` prop merged via `cn()` from `@/lib/utils`
    - Use design tokens from the Tailwind theme (the `@theme` block in globals.css)
    - Be Server Components by default (no `'use client'` directive)
    - Have proper TypeScript types for all props

    **1. Button (`src/components/ui/button.tsx`)**

    Props:
    - `variant`: 'gold' (default) | 'outline' | 'ghost'
    - `size`: 'sm' | 'md' (default) | 'lg'
    - `href`: optional string (renders as Next.js Link when provided, button when not)
    - `children`, `className`, standard button/anchor HTML attributes

    Styling:
    - **gold variant (default):** `bg-gold text-black font-semibold` with hover `bg-gold-500` (darker gold). This is the primary CTA style per DSGN-05.
    - **outline variant:** `border-2 border-gold text-gold` on dark backgrounds, hover fills gold. For use on hunter-green/black sections.
    - **ghost variant:** `text-gold hover:underline` -- minimal, for secondary actions on dark backgrounds.
    - Sizes: sm (px-4 py-2 text-sm), md (px-6 py-3 text-body), lg (px-8 py-4 text-body-lg)
    - Rounded: `rounded-sm` (subtle rounding, not pill-shaped -- premium feel)
    - Transition: `transition-colors duration-200`
    - Focus: `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-gold`

    IMPORTANT accessibility note on gold text: The `outline` and `ghost` variants use gold text. These MUST ONLY be used on dark backgrounds (hunter-green, black). They will fail WCAG AA on white/light backgrounds. Add a JSDoc comment on the component documenting this constraint.

    When `href` is provided, render as `<Link>` from next/link. Otherwise render as `<button>`.

    **2. Container (`src/components/ui/container.tsx`)**

    Props:
    - `size`: 'default' (max-w-[72rem]) | 'narrow' (max-w-[48rem])
    - `children`, `className`

    Styling: `mx-auto px-6 md:px-8` with the appropriate max-width. This is the horizontal constraint that keeps content from going edge-to-edge.

    **3. SectionHeading (`src/components/ui/section-heading.tsx`)**

    Props:
    - `heading`: string (the main heading text)
    - `tagline`: optional string (smaller text above heading, uppercase, tracking-wide)
    - `description`: optional string (paragraph below heading)
    - `align`: 'left' (default) | 'center'
    - `accentLine`: boolean (default true) -- gold accent line below heading
    - `headingAs`: 'h1' | 'h2' (default) | 'h3' -- the semantic HTML element
    - `dark`: boolean (default false) -- switches text colors for dark backgrounds
    - `children`, `className`

    Styling:
    - Tagline: `text-sm font-sans uppercase tracking-widest text-gold font-semibold mb-3` (gold text is acceptable here ONLY if used on dark backgrounds; on light backgrounds, use `text-hunter-green-600` instead). Handle this via the `dark` prop: when `dark` is true, tagline is gold; when false, tagline is hunter-green-600.
    - Heading: `font-serif` with size based on `headingAs` (h1 = text-h1, h2 = text-h2, h3 = text-h3). Color: when dark, text-white; when light, text-neutral-900.
    - Accent line: `w-16 h-0.5 bg-gold mt-4` (a short gold underline, not full-width)
    - Description: `text-body-lg mt-4 max-w-[48rem]` with muted color (text-neutral-600 on light, text-neutral-300 on dark)
    - Alignment: center variant adds `text-center mx-auto` and centers the accent line

    **4. Card (`src/components/ui/card.tsx`)**

    Props:
    - `hover`: boolean (default true) -- adds gold hover accent
    - `children`, `className`

    Styling:
    - `bg-white rounded-sm p-6 md:p-8`
    - `shadow-sm` default, `hover:shadow-md` when hover enabled
    - When hover enabled: `border border-transparent hover:border-gold/30 transition-all duration-300`
    - No gold text anywhere -- gold is only on the hover border

    **5. Divider (`src/components/ui/divider.tsx`)**

    Props:
    - `className`

    Styling: `h-px bg-gold/40 w-full` -- a subtle gold horizontal line. Used between sections per DSGN-05.

    **6. Section (`src/components/ui/section.tsx`)**

    Props:
    - `background`: 'white' (default) | 'light-green' | 'hunter-green' | 'black'
    - `padding`: 'default' | 'none'
    - `id`: optional string (for anchor links)
    - `children`, `className`

    Styling:
    - Background map:
      - white: `bg-white text-neutral-900`
      - light-green: `bg-hunter-green-50 text-neutral-900`
      - hunter-green: `bg-hunter-green text-white`
      - black: `bg-neutral-950 text-white`
    - Default padding: `py-section` (6rem vertical, from theme) with responsive `py-section-sm` on mobile via `py-16 md:py-24` (using standard spacing as fallback if custom spacing token has issues)
    - Wraps children in Container automatically
    - Renders as `<section>` HTML element
